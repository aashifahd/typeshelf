# Code of Conduct

Typeshelf adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal
attacks and discriminatory language are not accepted in issues, pull requests, discussions or any other
project space.

## Reporting

Report unacceptable behaviour privately to the maintainers at CenoDigital through the contact details on
the project's GitHub organisation page. Reports are handled confidentially. Maintainers may remove
content, or block people from the project, to enforce this code.
